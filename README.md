### Cat & Dog Image Classifier — CNN Image Classification

Built a convolutional neural network (CNN) image classifier to distinguish between cats and dogs using labeled image data. Preprocessed and normalized images, trained the model to recognize visual patterns, and evaluated classification performance on unseen images.

**Tools:** Python, TensorFlow/Keras, NumPy, Matplotlib

**What I did:**

* Prepared and normalized image data for model training
* Built and trained a CNN for binary image classification
* Used training and validation data to monitor model performance
* Evaluated predictions on images outside the training set
* Visualized model performance and sample predictions to identify strengths and errors

**Skills demonstrated:** Python, machine learning fundamentals, image classification, data preprocessing, model evaluation, data visualization
